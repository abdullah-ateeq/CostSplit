# CostSplit

CostSplit is a modern Android application built with Jetpack Compose that makes splitting expenses among friends, family, or colleagues simple, precise, and fair.

## Features

* **Multiple Allocation Methods**: Split bills equally, by shares, or by percentages.
* **Precise Math**: Uses exact calculations to avoid floating-point errors, ensuring that every cent is accounted for and no rounding errors occur.
* **Currency Support**: Built-in support for multiple currencies, along with the ability to add custom currencies.
* **Modern UI**: Intuitive and beautiful user interface built entirely with Jetpack Compose following Material Design 3 guidelines.
* **Real-time Validation**: Validates shares and percentages on the fly, offering instant feedback if inputs do not add up to 100%.

## Tech Stack

* **Language**: Kotlin
* **UI**: Jetpack Compose
* **Architecture**: MVVM (Model-View-ViewModel)
* **Navigation**: Jetpack Navigation for Compose
* **State Management**: Kotlin StateFlow
* **Minimum SDK**: 24 (or as configured in `build.gradle.kts`)

## Getting Started

### Prerequisites
* Android Studio (Ladybug or later recommended)
* JDK 17+

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abdullah-ateeq/CostSplit.git
   ```
2. Open the project in Android Studio.
3. Build and run the app on an emulator or physical device.
